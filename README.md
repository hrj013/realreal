# realreal
# 🌱 Eco Jump

> 게임을 하면서 환경보호도 함께 실천하는 환경보호 점프 게임

---

1. 프로젝트 소개

지난 학기 환경평가 점수가 개인의 노력, 국가의 노력, 사회의 노력을 모두 반영한다는 것을 알게 되었습니다. 그중에서도 저는 개인의 노력이 가장 중요하다고 느꼈고, 개인이 환경을 위해 더 노력하게 하려면 어떻게 해야 할지 고민하게 되었습니다.

그러다 환경보호 실천이 게임처럼 즐겁다면 더 많은 사람들이 실천하지 않을까? 라는 생각이 들었습니다. 그리고 게임을 할 때도 환경보호를 조금씩 실천할 수 있으면 좋겠다는 마음으로 이 앱을 만들었습니다.

Eco Jump는 발판을 따라 높이 올라가는 점프 게임입니다. 텀블러 사용, 대중교통 이용, 쓰레기 줍기 같은 실제 환경보호 활동을 사진으로 인증하면 그린 포인트를 얻고, 이 포인트로 게임에 도움이 되는 물약과 스킨을 살 수 있습니다. 환경을 지키는 행동이 곧 게임을 더 재미있게 만드는 보상이 됩니다.

---

2. 사용 방법

처음 시작하기
1. 첫 화면의 회원가입 탭에서 아이디와 비밀번호(4자 이상)를 입력해 가입합니다.
2. 로그인 탭에서 로그인합니다.

게임 하기
1. GAME START 버튼을 누르면 게임이 시작됩니다.
2. 마우스로 캐릭터 방향을 드래그했다가 놓으면 그 방향으로 점프합니다. 멀리 끌수록 더 강하게 점프합니다.
3. 발판을 밟으며 최대한 높이 올라가세요. 바닥에 떨어지면 게임이 끝납니다.
4. 게임이 끝나면 최고 높이, 점수, 플레이 시간이 자동으로 저장됩니다.

물약 사용하기
- 게임 화면 아래쪽의 물약 버튼을 클릭하거나 키보드 1~4번을 눌러 사용합니다.

| 키 | 물약 |
|---|---|
| 1 |  점수 2배 |
| 2 |  점수 3배 |
| 3 |  점프 높이 2배 |
| 4 |  캐릭터 크기 2배 |

부활 물약은 게임 오버가 되었을 때 나타나는 선택 화면에서 사용합니다.

환경보호 활동 인증하기
1. 왼쪽 메뉴에서 환경보호 보상 페이지로 이동합니다.
2. 활동 인증 탭에서 활동을 고르고 사진을 업로드한 뒤 AI 사진 인증하기를 누릅니다.
3. 결과에 따라 포인트가 바로 지급되거나, 관리자 검토를 기다립니다.
4. 보상 상점 탭에서 모은 포인트로 스킨과 물약을 구매합니다.

3. 주요 기능 설명

점프 게임
- 마우스 드래그로 점프 방향과 세기를 조절하는 조작 방식
- 높이 올라갈수록 발판이 좁아지고 간격이 넓어지는 **난이도 상승** (500m마다 단계 상승)
- 게임 결과(점수, 최고 높이, 플레이 시간)를 데이터베이스에 저장하며, 같은 게임이 중복 저장되지 않도록 방지

AI 환경보호 활동 인증
사진을 올리면 Gemini가 선택한 활동과 관련된 증거가 있는지 분석합니다.

| 활동 | 포인트 |
|---|---|
| 텀블러 사용 | 10P |
| 대중교통 이용 | 15P |
| 자전거 또는 걷기 | 15P |
| 재활용 | 10P |
| 일회용품 줄이기 | 10P |
| 쓰레기 줍기 | 20P |
| 다회용 용기 사용 | 15P |
| 기타 환경보호 활동 | 10P |

- 같은 활동은 하루에 한 번만 인증할 수 있습니다.
- AI가 확실하게 판단하면 자동 승인 또는 실패 처리되고, 판단이 애매하면 관리자 검토 대기로 넘어갑니다.
- AI 분석에 실패하거나 API 키가 없는 경우에도 앱이 멈추지 않고 관리자 검토로 접수됩니다.
- 내 인증 내역에서 AI의 판단과 근거를 확인할 수 있습니다.

보상 상점
- 스킨: 나뭇잎(50P), 바다(100P), 무지개(200P). 구매한 스킨은 상점에서 장착하거나 기본 스킨으로 되돌릴 수 있습니다.
- 물약: 구매하면 인벤토리에 보관되고, 게임에서 사용할 때 1개씩 소모됩니다.

| 물약 | 가격 | 효과 |
|---|---|---|
|  부활 물약 | 150P | 게임 오버 후 현재 게임을 이어서 진행 |
|  점수 2배 물약 | 50P | 이번 게임의 점수를 2배로 |
|  점수 3배 물약 | 100P | 이번 게임의 점수를 3배로 |
|  점프 높이 2배 물약 | 100P | 점프 높이를 2배로 (중첩 사용 가능) |
|  캐릭터 크기 2배 물약 | 100P | 캐릭터 크기를 2배로 (중첩 사용 가능) |

- 점수 배수 물약은 한 게임에서 2배 또는 3배 중 하나만 사용할 수 있습니다.
- 점프 높이·캐릭터 크기 물약은 최대 8배까지 중첩할 수 있습니다.
- 물약 구매와 사용 내역은 모두 기록되며, 같은 사용 요청이 중복으로 차감되지 않도록 처리합니다.

관리자 검토
- 관리자 비밀번호로 접속해 AI가 판단하지 못한 인증 사진을 직접 확인합니다.
- 승인하면 포인트가 지급되고, 반려하면 사유를 함께 사용자에게 알려 줍니다.
- 검토 결과는 사용자가 다음에 접속했을 때 안내창으로 보여 줍니다.

4. 실행 방법

사전 준비
- Python 3.9 이상
- [Google Gemini API 키](https://aistudio.google.com/) (AI 사진 인증에 사용)

설치와 실행
```bash
1. 저장소 내려받기
git clone https://github.com/hrj013/realreal.git
cd realreal

2. 필요한 라이브러리 설치
pip install -r requirements.txt

3. 앱 실행
streamlit run app.py
```

Secrets 설정
프로젝트 폴더에 `.streamlit/secrets.toml` 파일을 만들고 아래 내용을 입력합니다.

```toml
GEMINI_API_KEY = "여기에_제미나이I_키를_입력"
admin_password = "원하는_관리자_비밀번호"
```

- `GEMINI_API_KEY`가 없으면 모든 인증 사진이 관리자 검토 대기로 접수됩니다.
- `admin_password`가 없으면 관리자 검토 탭을 사용할 수 없습니다.

데이터베이스
처음 실행하면 프로젝트 폴더에 `eco_jump.db`(SQLite) 파일이 자동으로 만들어지므로 따로 설정할 필요가 없습니다.

폴더 구조
```
realreal/
├── app.py               # 메인 화면 (로그인, 게임 실행)
├── requirements.txt
├── database/
│   └── db.py            # 데이터베이스 (사용자, 기록, 물약 등)
├── game/                # 게임 화면 (Streamlit 컴포넌트)
│   ├── index.html
│   ├── game.js
│   └── game.css
├── game_component/
│   └── __init__.py      # 게임을 Streamlit에 연결
└── pages/
    └── eco_reward.py    # 환경보호 인증, 보상 상점, 관리자 검토
```
